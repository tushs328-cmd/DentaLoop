# DentaLoop — Projects for Social Good

## Название

DentaLoop — сроки, которые важны человеку

## Слоган

Помогаем маленькой лаборатории не потерять заказ, который нельзя откладывать.

## Проблема

Доступное протезирование часто организуют небольшие клиники и лаборатории с ограниченным количеством людей. Заказы живут в чатах, блокнотах и памяти: теряются оттенок, этап, пожелания врача и срок. Для пожилого пациента, малообеспеченной семьи или льготника срыв может означать лишнюю поездку, потерянный рабочий день и дополнительные расходы. Мы не выдумываем статистику — показываем, как инструмент помогает на уровне конкретного рабочего процесса.

## Решение

DentaLoop превращает заказ в прозрачный цикл. Техник указывает код пациента вместо ФИО, отмечает социальный заказ и выбирает обезличенную категорию поддержки. Система создаёт чек-лист по типу работы, ставит заказ на канбан-доску, подсвечивает риск и даёт более ранний порог внимания социальным заказам. Врач получает публичную ссылку с понятным этапом и ожидаемой датой без чувствительных данных.

## Impact

1. Лаборатория раньше видит заказ, который нельзя потерять среди обычных задач, и может перераспределить внимание до срыва срока.
2. Пациенту и врачу не нужно звонить только ради вопроса «на каком этапе заказ»: ссылка показывает этап и ориентировочную дату.
3. Руководитель маленькой лаборатории видит честную локальную сводку социальных заказов и может обсуждать узкие места по фактическому рабочему списку, без выдуманных метрик.

## Как работает

Создать заказ → выбрать тип работы и социальную категорию без ФИО → получить этапы → двигать карточку по доске → увидеть риск → открыть public status → распечатать заказ-наряд. Панель Impact считает только сохранённые социальные заказы. «Готово вовремя» означает этап «Отправка» с реальным `completedAt` до планового срока; это не медицинская метрика.

## Технологии

Node.js 20, Express, обычные HTML/CSS/JavaScript, локальное JSON-хранилище, Node test runner. Внешние ключи для основного сценария не нужны.

## Что сделано во время хакатона

Всё содержимое текущей фичи создано в окне хакатона поверх MVP: социальный режим, категории без персональных данных, приоритет и строгий риск, панель Impact, 4 социальных демо-заказа, приватный public status, тесты, документация и сценарий видео.

## Что не успели

Не делали авторизацию, платежи, медицинские рекомендации, мессенджеры и мобильное приложение. Реальный AI-провайдер не является обязательным и не тестировался с ключом; без ключа приложение работает с явной подписью `Без ИИ`.

## Запуск

```powershell
npm install
npm test
npm start
```

Инструмент учёта заказов, не медицинский продукт; не гарантирует результатов.
