# DentaLoop

DentaLoop — спокойная доска заказов для зуботехника и маленькой лаборатории. Она превращает заказ на коронку, мост или протез из сообщения в мессенджере в понятный рабочий цикл: код пациента, тип работы, оттенок VITA, этапы, срок и безопасная публичная ссылка для врача.

> Инструмент учёта заказов, не медицинский продукт.

## Быстрый старт

```powershell
cd C:\Users\ertai\Desktop\hakaton\EvoHacks2_Project
npm install
npm start
```

Откройте http://localhost:3000. Ключ API не нужен: кнопка подсказки работает в детерминированном режиме «Без ИИ». Для опционального ИИ скопируйте `.env.example` в `.env` и задайте `LLM_API_KEY` или `OLLAMA_URL`.

## Что сделано

- создание заказа с приватным кодом пациента, клиникой/врачом, зубом, типом работы, VITA, материалом, сроком и заметками;
- шесть профессиональных шаблонов этапов с длительностями;
- канбан с drag-and-drop и кнопками предыдущего/следующего этапа, доступными с клавиатуры;
- расчёт «в срок / риск / просрочен» на основе срока и оставшихся этапов;
- безопасная публичная страница `/status/<token>` без клиники, врача, заметок и материала;
- печатный A4 заказ-наряд, экспорт и импорт JSON;
- пять демо-заказов с заметным бейджем «Демо» и кнопкой сброса;
- русский/английский, светлая/тёмная тема, адаптивная вёрстка и базовые состояния ошибок;
- шаблонная памятка «Без ИИ»; при наличии ключа или Ollama отображается отдельный бейдж `AI`.

## Структура и ограничения

- `server.js` — Express API, валидация, расчёты риска, JSON-хранилище;
- `public/` — обычные HTML/CSS/JS без сборки;
- `tests/` — шесть регрессионных тестов для API и доменной логики;
- `data/orders.json` — локальные данные, создаются при первом запуске и не коммитятся;
- авторизация, платежи, медицинские рекомендации, мессенджеры и мобильное приложение намеренно не входят в MVP;
- тема EvoHacks 2 на момент сборки не опубликована: формулировка демо оставлена нейтральной.
