**0:00–0:15 — контекст.** «Заказы зуботехника теряются между чатами: оттенок, этап и срок приходится держать в голове. DentaLoop собирает это в одну доску».

**2:05–2:20 — операционные детали.** Показать печать заказ-наряда, затем переключить язык и тему. Нажать «Подсказка по заказу»: без ключа виден бейдж «Без ИИ» и честная шаблонная памятка.

**2:20–2:30 — финал.** «DentaLoop — узкий workflow для реальной зуботехнической логики: меньше ручной памяти, понятнее срок, безопаснее статус для врача. Это инструмент учёта заказов, не медицинский продукт».
