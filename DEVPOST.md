# DentaLoop

## Название

DentaLoop — лаборатория без пропущенных сроков

## Слоган

От сообщения в чате — к понятному этапу работы.

## Проблема

Заказы на коронки, мосты и протезы часто живут в мессенджерах, блокнотах и памяти. Теряются оттенок, пожелания врача, текущий этап и срок сдачи.

## Как работает

Техник создаёт заказ по коду пациента, выбирает профессиональный шаблон работы и получает чек-лист этапов. Заказ двигается по канбан-доске, а DentaLoop подсвечивает риск по сроку. Врач получает публичную ссылку, где видит только код, тип работы, текущий этап и ожидаемую дату.

## Технологии

Node.js 20, Express, обычные HTML/CSS/JavaScript, JSON-хранилище без внешней базы и без обязательного API-ключа.

## Что сделано

Создание заказа, шесть типов работ, этапы с длительностями, drag-and-drop канбан, кнопки для клавиатуры, расчёт риска, безопасный public status, печать, импорт/экспорт, демо-данные, RU/EN, светлая/тёмная тема и понятный бейдж `AI`/`Без ИИ`.

## Что готово заранее

По состоянию входной папки до сборки были только материалы задания. MVP, интерфейс, серверная логика, тесты и документы подготовлены в рамках хакатонной сессии.

## Что не успели / сознательно не делали

Не делали авторизацию, платежи, медицинские рекомендации, интеграции с мессенджерами и нативное приложение. ИИ-интеграция зависит от внешнего провайдера и поэтому остаётся опциональной; без ключа работает честный шаблонный режим.

## Запуск

```powershell
npm install
npm test
npm start
```

Инструмент учёта заказов, не медицинский продукт.
