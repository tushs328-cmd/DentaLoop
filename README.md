# DentaLoop — Projects for Social Good

DentaLoop помогает небольшой зуботехнической лаборатории не терять сроки по заказам, особенно когда протез нужен пожилому человеку, малообеспеченной семье или льготнику. Для такого человека срыв срока — это дополнительная поездка, потерянный день и новые расходы. Приложение делает социальный заказ заметным внутри лаборатории, но не раскрывает категорию поддержки врачу или пациенту через публичную ссылку.

> Инструмент учёта заказов, не медицинский продукт; не гарантирует результатов и не заменяет решения специалиста.

## Быстрый старт

```powershell
cd C:\Users\ertai\Desktop\hakaton\EvoHacks2_Project
npm install
npm start
```

Откройте http://localhost:3000. Ключ API не нужен. Без ключа подсказка по заказу честно помечена `Без ИИ` и использует шаблонную памятку. Для опционального режима задайте `LLM_API_KEY` или `OLLAMA_URL` в локальном `.env`; секреты не входят в репозиторий.

## Что умеет MVP

- создаёт обычный или социальный заказ по коду пациента, без ФИО;
- хранит только категорию социальной поддержки: пожилой пациент, малообеспеченная семья, льготная категория или другое;
- выдаёт чек-лист по одному из шести типов работ и показывает заказ на канбан-доске;
- подсвечивает социальные заказы SVG-значком, сортирует их выше при одинаковом сроке и применяет более ранний порог риска;
- показывает панель пользы на реальных данных хранилища: всего социальных заказов, готово вовремя, в риске, просрочено и доля готовых вовремя;
- выдаёт публичную ссылку только с кодом, типом работы, текущим этапом и ожидаемой датой — без категории, клиники, врача и заметок;
- печатает заказ-наряд, экспортирует и импортирует JSON, поддерживает RU/EN и светлую/тёмную тему;
- содержит 9 помеченных демо-заказов, из них 4 социальных, и кнопку сброса демо.

Показатель «готово вовремя» в MVP считается только по реальным сохранённым заказам: заказ должен быть на этапе «Отправка», иметь `completedAt` и завершиться не позднее срока. Это рабочая эвристика для учёта, не статистика качества лечения.

## Структура

- `server.js` — Express API, JSON-хранилище, валидация, риск и impact-расчёт;
- `public/` — HTML/CSS/JS без сборки;
- `tests/` — регрессионные тесты доменной логики, приватности и изолированного хранилища;
- `data/orders.json` — локальные данные, создаются при первом запуске и игнорируются Git;
- `DEVPOST.md` и `DEMO_SCRIPT.md` — материалы подачи.

## Тесты

```powershell
npm test
```

Тесты используют временный каталог и не изменяют рабочий `data/orders.json`.

## Сделано на хакатоне и ограничения

Основной код MVP, социальный режим, панель пользы, тесты и материалы подачи созданы в окне хакатона поверх существующего DentaLoop. Авторизация, платежи, медицинские рекомендации, интеграции с мессенджерами и нативное приложение не входят в scope. Внешний AI-провайдер остаётся опциональным; без него продукт полностью работает в шаблонном режиме.
